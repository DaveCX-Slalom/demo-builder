# Glossary

- **At risk** — deal at or above the at-risk ratio (default 80%) of its stage SLA.
- **Stalled** — deal past its stage SLA.
- **Weighted value** — amount × stage win probability.
- **Forecast** — funded to date + weighted value of open deals expected to close this quarter.
- **Widget** — a dashboard section rendered from config via the registry.
- **Persona** — an audience definition: scope (all/own deals), focus line, questions.
